# WORLD//01 — Mission 000 / Interactive Prototype V1

Codice sorgente del primo prototipo interattivo di **WORLD//01 — MISSION 000: FIRST CONTACT**.

## Prototipo pubblicato

https://world-01-mission.piste.chatgpt.site

## Percorso incluso

1. Landing page WORLD//01
2. Registrazione Candidate con Agent ID casuale e non sequenziale
3. Dossier `STATUS: CANDIDATE`
4. Primo minuto di Mission 000 — The Inherited Relay
5. Relay Tokyo → città del Candidate
6. Frammento audio con chain of custody
7. Secondo frammento in una email narrativa simulata
8. Rivelazione `YOU ARE THE SECOND WITNESS`
9. Case 000-A — Verify the Source

## Stato tecnico

Questa è una versione MVP a stato locale. Agent ID, profilo Candidate, telemetria di test ed email narrativa sono simulati nel browser. Non sono ancora collegati a database, autenticazione o invio email reale: queste integrazioni verranno aggiunte soltanto dopo la validazione del flusso.
